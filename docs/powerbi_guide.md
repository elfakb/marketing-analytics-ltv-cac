# Power BI guide / Power BI kılavuzu

The Streamlit app is the primary dashboard. This guide rebuilds the same report in Power BI Desktop
from the CSVs in `powerbi/data/` (generated by `python -m src.marts`).
Streamlit uygulaması ana dashboard'dur; bu kılavuz aynı raporu `powerbi/data/` altındaki CSV'lerle Power BI Desktop'ta kurar.

## 1. Load / Yükle
Home → Get data → Text/CSV → load all files in `powerbi/data/`.

| Table | Type | Grain |
|---|---|---|
| `fact_campaign_daily` | fact | date × campaign |
| `fact_orders` | fact | order |
| `dim_campaign` | dimension | campaign (channel, name, objective) |
| `dim_customer` | dimension | customer (segment, LTV 90/180) |
| `dim_date` | dimension | day |
| `mart_channel_segment`, `mart_conversion_trap` | pre-aggregated | channel × segment / campaign |

## 2. Relationships / İlişkiler (Model view)
- `dim_date[date]` 1 → * `fact_campaign_daily[date]`
- `dim_campaign[campaign_id]` 1 → * `fact_campaign_daily[campaign_id]`
- `dim_campaign[campaign_id]` 1 → * `fact_orders[campaign_id]`
- `dim_campaign[campaign_id]` 1 → * `dim_customer[acquisition_campaign_id]`
- `dim_customer[customer_id]` 1 → * `fact_orders[customer_id]`
- Set `dim_date` as date table. Single-direction filters.

## 3. DAX measures
```DAX
Spend         = SUM ( fact_campaign_daily[spend] )
Revenue       = SUM ( fact_campaign_daily[revenue] )
COGS          = SUM ( fact_campaign_daily[cogs] )
Profit        = [Revenue] - [COGS] - [Spend]
Impressions   = SUM ( fact_campaign_daily[impressions] )
Clicks        = SUM ( fact_campaign_daily[clicks] )
Leads         = SUM ( fact_campaign_daily[leads] )
Conversions   = SUM ( fact_campaign_daily[conversions] )
New Customers = SUM ( fact_campaign_daily[new_customers] )

CTR  = DIVIDE ( [Clicks], [Impressions] )
CPC  = DIVIDE ( [Spend], [Clicks] )
CPL  = DIVIDE ( [Spend], [Leads] )
CPA  = DIVIDE ( [Spend], [Conversions] )
CVR  = DIVIDE ( [Conversions], [Clicks] )
CAC  = DIVIDE ( [Spend], [New Customers] )
ROAS = DIVIDE ( [Revenue], [Spend] )          -- BLANK for Organic (no spend)

Paid Revenue = CALCULATE ( [Revenue], dim_campaign[objective] <> "Organic" )
Paid ROAS    = DIVIDE ( [Paid Revenue], [Spend] )

-- LTV only on customers observed for the full window (ltv_90 is blank otherwise)
Avg LTV 90   = AVERAGE ( dim_customer[ltv_90] )
Avg LTV 180  = AVERAGE ( dim_customer[ltv_180] )
Repeat Rate 90 = AVERAGE ( dim_customer[repeat_90] )

-- Cohort CAC on the same matured cohort (signup <= 2025-10-03)
Matured Spend = CALCULATE ( [Spend], dim_date[date] <= DATE ( 2025, 10, 3 ) )
Matured Cust  = CALCULATE ( COUNTROWS ( dim_customer ), NOT ISBLANK ( dim_customer[ltv_90] ) )
Cohort CAC    = DIVIDE ( [Matured Spend], [Matured Cust] )
LTV:CAC       = DIVIDE ( [Avg LTV 90], [Cohort CAC] )
Net LTV 90    = [Avg LTV 90] - [Cohort CAC]

Revenue vs PP = VAR prev = CALCULATE ( [Revenue], DATEADD ( dim_date[date], -1, MONTH ) )
                RETURN DIVIDE ( [Revenue] - prev, prev )
```
> `Cohort CAC`/`LTV:CAC` are meaningful when sliced by channel/campaign (via `dim_customer` → `dim_campaign`).
> Use `mart_channel_segment` for the channel × segment heatmap (it already contains the net LTV).

## 4. Pages / Sayfalar
1. **Overview** – KPI cards (Spend, Revenue, Profit, Paid ROAS, CAC, Conversions) + monthly line chart + channel slicer.
2. **Channel Performance** – bar: Profit by channel; bar: ROAS; table with CTR/CPC/CPL/CPA/CVR/CAC; funnel (Impressions → Clicks → Leads → Conversions).
3. **Campaign Performance** – clustered bar Revenue vs Profit by campaign; table with rank; scatter from `mart_conversion_trap` (X = cvr, Y = ltv, size = spend, legend = quadrant).
4. **Customer Segments** – matrix visual from `mart_channel_segment` (rows = segment, columns = acquisition_channel, values = net_ltv, conditional formatting red→green).

Save the report as `powerbi/Marketing_Performance.pbix` and add screenshots to `docs/`.
